# Interactive Hover Card Component Grid

## 1. Project Overview

The Interactive Hover Card Component Grid is a responsive web design project developed using HTML5 and CSS3. It displays multiple stylish cards in a grid layout. Each card reveals additional information when the user moves the mouse pointer over it using CSS pseudo-classes.

## 2. Objectives

- To create an attractive card component grid using HTML.
- To implement hover effects using CSS pseudo-classes.
- To reveal hidden information through smooth transitions.
- To create a responsive layout using CSS Grid.
- To improve the appearance and user experience of a website.

## 3. Technologies Used

- **HTML5:** Used to create the structure and content of the cards.
- **CSS3:** Used for styling, animations and hover effects.
- **CSS Grid:** Used to arrange cards in a responsive grid.
- **CSS Media Queries:** Used to make the design responsive.

## 4. Project Features

1. Six attractive interactive cards.
2. Different gradient backgrounds.
3. Front and hidden back content.
4. Smooth hover animations.
5. Additional information displayed on hover.
6. Responsive design for desktop, tablet and mobile screens.
7. Keyboard focus accessibility.

## 6. Implementation Tasks

### Task 1: Build HTML Markup

Created HTML markup for a grid of six cards. Each card contains front content and hidden back content.

### Task 2: Implement Hover Effects

Used the CSS `:hover` pseudo-class to hide the front content and reveal additional information with smooth transition effects.

### Task 3: Implement Responsive Design

Used CSS Grid and media queries to adjust the card layout for different screen sizes.

- Desktop: Three columns.
- Tablet: Two columns.
- Mobile: One column.

## 7. How to Run the Project

1. Download or copy the project folder.
2. Open the folder in Sublime Text.
3. Ensure that `index.html`, `style.css` and `README.md` are present.
4. Open `index.html` in Google Chrome.
5. Move the mouse pointer over the cards.
6. Observe the additional information and animation effects.
7. Resize the browser window to test responsiveness.

## 8. Expected Output

The project displays six colorful cards in a responsive grid. When the user hovers over a card, its front content disappears and additional information becomes visible with a smooth animation.
